# 모닝브루 카페 주문 웹앱

HTML, CSS, JavaScript만으로 만든 카페 메뉴 주문 및 관리자 확인 웹앱입니다. 메뉴 옵션을 선택해 주문하고 재고를 차감할 수 있으며, 관리자 대시보드에서 주문을 제조 완료 처리하고 재고를 확인할 수 있습니다.

## 링크

- **GitHub 저장소:** [lsc0772/vibe-midterm-202602406](https://github.com/lsc0772/vibe-midterm-202602406)
- **배포 사이트:** [모닝브루 카페 주문 웹앱 열기](https://lsc0772.github.io/vibe-midterm-202602406/)

저장소 이름은 `vibe-midterm-202602406`이며 공개(Public) 저장소입니다.

## 주요 기능

- 아메리카노, 카페라떼, 바닐라라떼, 말차라떼, 자몽허니블랙티 5종
- 샷 추가(+500원), 시럽 추가(+0원)
- 장바구니 메뉴 담기·삭제 및 합계 계산
- 주문 접수, 주문 번호 표시, 메뉴별 재고 차감 및 품절 처리
- 주문 메뉴와 관리자 대시보드 간 페이지 내 전환
- 관리자 주문 현황 및 제조 완료 처리
- 메뉴별 재고와 판매 가능 상태 확인
- 주문 및 화면 모드의 브라우저 로컬 저장
- 사용자가 직접 선택할 수 있는 모바일·데스크톱 레이아웃
- 푸터에 학과(법행정세무학과(야)), 학번(202602406), 이름(이서찬) 표시

## 저장소 및 배포 상태

- GitHub Pages 주소는 정상 응답하는 것을 확인했습니다.
- Pages는 원격 저장소의 소스를 배포하므로, 로컬에서 아직 push하지 않은 변경사항은 배포된 화면과 다를 수 있습니다.

## 실행 방법

### 로컬에서 실행

1. 저장소를 내려받거나 복제합니다.
   ```powershell
   git clone https://github.com/lsc0772/vibe-midterm-202602406.git
   cd vibe-midterm-202602406
   ```
2. `index.html`을 브라우저에서 엽니다.

정적 파일로 구성되어 별도의 패키지 설치나 빌드가 필요하지 않습니다. VS Code에서 작업하는 경우 Live Server 같은 정적 파일 서버로 열어도 됩니다.

## 사용법

1. **주문 메뉴**에서 음료의 샷·시럽 옵션을 선택하고 **장바구니 담기**를 누릅니다.
2. 장바구니에서 메뉴와 합계를 확인하고 **주문하기**를 누릅니다.
3. 상단의 **관리자 대시보드** 버튼을 눌러 접수 주문과 재고를 확인합니다.
4. 준비가 끝난 주문은 **제조 완료 처리**를 누릅니다.
5. **모바일** 또는 **데스크톱** 버튼으로 화면 레이아웃을 바꿉니다. 선택은 현재 브라우저에 저장되어 다음 방문에도 유지됩니다.

## 데이터 저장 및 제한

- 주문, 재고, 장바구니와 레이아웃 모드는 브라우저 `localStorage`에 저장됩니다.
- 저장 데이터는 브라우저·기기별이므로 다른 기기나 관리자와 자동 공유되지 않습니다.
- 서버, 로그인, 결제, 실시간 동기화는 포함하지 않습니다. 실제 매장 운영에는 백엔드와 인증·결제 연동이 필요합니다.
